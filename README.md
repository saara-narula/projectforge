# ⚡ ProjectForge - Personalized Project Recommender

> An intelligent, hybrid project recommendation engine that matches students, self-taught developers, and researchers with real-world projects based on their **academic discipline**, **target domains**, **current tech stack**, **experience level**, and **free-form research interests**.

Primary Stack: **HTML5**, **CSS3**, and **Python (Flask)**.

---

## 🚀 Quick Start Guide

### 1. Run the Web Server

Open Command Prompt (CMD) or the VS Code terminal and navigate to the project folder:

```bash
cd path\to\project-recommender
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the Flask application:

```bash
python app.py
```

### 2. Open in Your Browser

Visit: http://127.0.0.1:5001

*Note: Ensure that the Flask application is configured to run on port 5001.*
